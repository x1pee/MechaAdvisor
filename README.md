# MechaAdvisor

**Current · Working prototype**

A Windows companion for Mechabellum with a small unit matchup database, purchase and technology suggestions, and a deployment planner. Its experimental live mode reads the game process and camera state and draws placement hints in a separate overlay. It does not write game memory or inject code; purchases and movement are performed by the player.

Project information and the Windows download are available on the **[official website](https://pmxp.fun/portfolio/#mechabellum)**. This repository contains the project description only. Application code, installers, portable archives and release attachments are not distributed here.

## Data and evidence

The current prototype uses 19 authored heuristic rules. Its demo and planning pipeline have been tested; compatibility with the current game build and battle effectiveness remain unverified. No developer approval, strongest-move result, or protection from sanctions is claimed.

## Русский

**Current · Работающий прототип**

Помощник для Mechabellum на Windows: небольшая база взаимодействий юнитов, рекомендации покупок и улучшений, планировщик расстановки. Экспериментальный live-режим читает процесс игры и состояние камеры и показывает позиции отдельным оверлеем. Программа не записывает данные в память игры и не внедряет код; покупки и перемещения выполняет игрок.

Описание проекта и загрузка для Windows доступны на **[официальном сайте](https://pmxp.fun/portfolio/#mechabellum)**. В этом репозитории размещено только описание. Код приложения, установщики, portable-архивы и файлы релизов здесь не распространяются.

Текущая версия использует 19 авторских эвристик. Демо и расчёт плана проверены; совместимость с текущей версией игры и эффективность в бою пока не подтверждены. Одобрение разработчика, лучший ход и отсутствие санкций не гарантируются.
